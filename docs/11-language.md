# Язык в Яндекс Играх

После инициализации SDK адаптер читает `environment.i18n.lang` до сигналов готовности и старта игры. Сейчас интерфейс доступен только на русском: если платформа сообщает другой язык или SDK недоступен, выбирается единственная поддерживаемая локаль `ru`, которая записывается в `html.lang`. Автономная версия не обращается к SDK.

Одноязычная игра обязана читать язык платформы согласно [требованию Яндекс Игр](https://yandex.ru/dev/games/doc/ru/requirements/2/14). [Рекомендации по языкам и доменам](https://yandex.ru/dev/games/doc/ru/concepts/languages-and-domains) описывают резервные языки для многоязычных игр; добавление английского требует отдельного перевода интерфейса.
