# Сквозная проверка в Chrome

Тесты запускают production-сборки Vite на `127.0.0.1:4273` и `127.0.0.1:4274` и управляют установленным Google Chrome через Playwright. Порт 4173 не используется. Браузер Chromium при установке не скачивается.

```sh
PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm ci
npm run typecheck
npm test
npm run test:e2e
```

`npm run test:e2e` сначала пересобирает обе версии. Конфигурация ожидает Chrome по пути `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`. При другой установке нужно скорректировать `executablePath` в `playwright.config.ts`. Отчёты об ошибках и снимки находятся в игнорируемом `test-results/`.

Автономная версия проверяется без SDK; для версии Яндекс Игр запрос `/sdk.js` подменяется тестовым объектом YaGames с callback рекламы и событиями жизненного цикла. Реальная реклама недоступна без аккаунта Яндекс Игр: подмена проверяет взаимодействие приложения с API, но не доказывает показ рекламы на платформе.

Проверено на принятой основе T07: Google Chrome 157.0.8103.38, Playwright 1.64.1; 30 сквозных сценариев и 62 модульных теста прошли. Отдельная проверка типов сценариев:

```sh
npx tsc --ignoreConfig --noEmit --target ES2022 --module ESNext --moduleResolution Bundler --strict --skipLibCheck --lib ES2022,DOM playwright.config.ts tests/e2e/*.ts
```

Сценарии охватывают работу поля и подсказок, сохранение и восстановление, клавиатуру, адаптивную вёрстку, таймер и возврат назад, а также варианты рекламы, паузы SDK и двойной щелчок с задержкой 120 мс. Геометрия всех клеток и структура строк и клеток доступности проверяются для размеров 6, 8 и 10 на мобильном и настольном экранах, включая увеличение 10×10. Эти проверки и снимки не заменяют полную ручную визуальную проверку. Снимки `test-results/desktop.png` и `test-results/mobile.png` создаются успешными проверками вёрстки после восьми ходов по подсказкам.
