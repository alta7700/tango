# Браузерная игра

Запуск для разработки: `npm install`, затем `npm run dev`. Проверки: `npm run typecheck`, `npm test`, `npm run build`. Сборки находятся в `dist/standalone` и `dist/yandex`; standalone работает без внешних ресурсов.

Клетка меняется по циклу пусто → солнце → луна → пусто. Стрелки перемещают фокус, Enter или пробел меняют клетку, Delete или Backspace очищают её. Для поля 10 × 10 доступно увеличение с прокруткой внутри поля. Подсказка сначала объясняет ход, а кнопка «Применить» вносит его.

Состояние и счётчик партий хранятся в localStorage отдельно для каждой платформы: `tango:standalone:game:v1`, `tango:standalone:count:v1` и соответствующие ключи с `yandex`. Ошибочные ходы сохраняются вместе с историей отмены. Генерация и поиск подсказок выполняются в worker; при ошибке можно повторить действие.
