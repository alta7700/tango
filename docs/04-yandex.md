# Адаптер Яндекс Игр

`createGameContainer('yandex')` создаёт адаптер; без аргумента выбирается автономный режим. Перед взаимодействием с игрой вызовите `await container.initialize()`, а когда ресурсы загружены и интерфейс готов — `container.ready()`. При начале или возобновлении партии вызывайте `gameplayStart()`, при переходе в меню, победе или иной остановке — `gameplayStop()`. Подписка `onPauseChange` сразу сообщает текущее состояние и возвращает функцию отписки. Остановка игры, звука и таймера при паузе — ответственность интерфейса. При завершении работы вызовите `dispose()`.

SDK динамически загружается только для Яндекса по `/sdk.js`, затем вызывается `YaGames.init()`. SDK не включается в архив. Ошибка загрузки, отсутствие глобального объекта, отказ инициализации и ожидание более 10 секунд переводят адаптер в резервный режим без SDK. `ready()` перед инициализацией запоминается и отправляется единожды после неё. В автономном режиме видимость вкладки также передаётся через `onPauseChange`, без загрузки SDK. Видимость вкладки, события SDK и открытая реклама учитываются как независимые причины паузы. После снятия последней причины игровой процесс размечается как активный только если приложение ранее вызвало `gameplayStart()` и не вызвало `gameplayStop()`.

`requestHintReward()` ожидает закрытия рекламы или ошибки. После `onRewarded` выдаётся одна награда, даже если затем возникла ошибка. При отсутствии рекламы, ошибке либо закрытии до открытия подсказка бесплатна. Если реклама открылась либо SDK сообщил показ через `onClose(true)` и затем закрылась без награды, результат — `cancelled`, подсказка не выдаётся. Одинаковые одновременные запросы используют один результат; показы разных типов выполняются последовательно. Поздние и повторные callback игнорируются.

Ожидание открытия ограничено 10 секундами: при отсутствии callback подсказка бесплатна. После открытия ожидание ограничено 180 секундами: при тайм-ауте сохраняется полученная награда, а без неё подсказка бесплатна с причиной `error`: отсутствие ответа SDK считается сбоем, а не отменой пользователем. Тайм-аут снимает паузу, поскольку SDK не сообщил закрытие; если рекламный экран фактически остался открыт, адаптер не может это определить. Значения ограничений и загрузчик можно передать через `ContainerOptions` для тестов. `dispose()` завершает текущие ожидания и отменяет загрузку.

`showInterstitial()` ожидает закрытия, ошибки или тайм-аута. Частота показов и сохранение номера партии принадлежат интерфейсу: вызов перед партиями 3, 6, 9 и далее; повторный запуск или сброс текущей партии не увеличивает счётчик.

Аккаунта Яндекс Игр пока нет, поэтому реальная реклама не проверена. Проверяются заглушки SDK; готовый ZIP нужно проверить и загрузить после появления аккаунта. Источники: [подключение SDK](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about), [реклама](https://yandex.ru/dev/games/doc/ru/sdk/sdk-adv), [загрузка и геймплей](https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events), [события](https://yandex.ru/dev/games/doc/ru/sdk/sdk-events).
