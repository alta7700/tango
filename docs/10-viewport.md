# Размещение в окне

Экран занимает видимую высоту окна, а страница не прокручивается. Размер квадратного поля ограничен шириной и высотой доступной области; клетки и связи сохраняют свои пропорции. При увеличении поля 10×10 до 600 пикселей прокручивается только его область. Правила, подсказка и сообщение о победе при нехватке места прокручиваются внутри собственных панелей. Кнопки управления остаются вне прокручиваемых панелей. При малой высоте отступы уменьшаются.

Проверка: `npm run test:e2e`, включая `tests/e2e/viewport.spec.ts`. Сквозные сценарии проверяют Chrome на 1280×720, 1024×600, 390×844, 360×640 и 844×390, все размеры поля, панели, увеличение и изменение размера окна.
