# Отображение нарушений

После изменения поля прежние автоматические нарушения исчезают сразу. Новые показываются через 450 мс после последнего изменения; это проектное решение интерфейса. Ввод, сохранение, валидация, подсказки и определение победы выполняются без задержки. Сообщения подсказки, паузы, ожидания и уведомления не зависят от таймера.

Отмена и сброс считаются изменением поля и начинают новый отсчёт. При запуске новой партии прежний отсчёт отменяется. При восстановлении сохранения нарушения текущего поля отображаются сразу. При паузе или переходе в BFCache незавершённый отсчёт отменяется и после возвращения начинается заново; при уничтожении страницы он отменяется окончательно. Обычная перерисовка отсчёт не меняет.

Проверки: `npm run typecheck`, `npm test`, `npm run build`, `npx playwright test tests/e2e/standalone.spec.ts`. Сквозные проверки используют установленный Google Chrome и управляемые часы.
