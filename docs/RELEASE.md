# Выпуск Tango

## Сборка и проверка

Установите Node.js 24, npm и Python 3.9 или новее, затем в корне проекта выполните:

```sh
npm ci
npm run release
```

Команда выполняет проверку типов, unit-тесты и обе сборки. Затем она создаёт `artifacts/tango-standalone.zip` и `artifacts/tango-yandex.zip`, проверяет состав, ссылки на ресурсы, worker и CRC, распаковывает архивы во временные каталоги и выводит их абсолютные пути. Каждый каталог готов для раздачи статическим сервером, например `python3 -m http.server --directory ПУТЬ 8000`. В `artifacts/release.json` записаны версия, UTC-время, Git commit и ref, признак незакоммиченных изменений, размеры и SHA-256 архивов. Для манифеста принятого коммита повторите команду после его создания. Архивы и сборки не коммитятся.

В корне каждого ZIP находится `index.html` и необходимые ресурсы, без исходников и SDK. Это соответствует [требованию Яндекса к архиву](https://yandex.ru/dev/games/doc/ru/console/add-new-game/draft). Яндекс-сборка запрашивает `/sdk.js` у платформы; файл SDK не входит в архив ([подключение SDK](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about)). Автономная версия SDK не загружает.

## После появления аккаунта Яндекс Игр

Перед заполнением черновика прочитайте [проверку требований и прав](12-publication-audit.md): название Tango не подтверждено как свободное, а локальные тесты не заменяют модерацию и испытания на платформе.

1. Создайте черновик игры в консоли и загрузите `artifacts/tango-yandex.zip` в поле архива. Проверьте актуальные требования и доступные поля в [документации черновика](https://yandex.ru/dev/games/doc/ru/console/add-new-game/draft).
2. Укажите поддерживаемые платформы: компьютеры и мобильные устройства; язык игры — русский. Укажите фактическую ориентацию, возрастной рейтинг, категории, теги и ключевые слова. Не заявляйте поддержку телевизоров или облачных сохранений.
3. Заполните название, описание, сведения об игре и правила управления; подготовьте требуемые иконку, обложку, скриншоты и видео согласно текущим требованиям консоли. Проверьте остальные обязательные поля и параметры перед отправкой.
4. Протестируйте загруженный черновик на компьютере и телефоне, включая сохранение, паузу, рекламу и вознаграждение. SDK описывает [рекламу](https://yandex.ru/dev/games/doc/ru/sdk/sdk-adv), [загрузку и геймплей](https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events), а также [события паузы](https://yandex.ru/dev/games/doc/ru/sdk/sdk-events).

Сейчас аккаунта нет: загрузка, модерация и реальный показ рекламы не выполнялись. Готовый ZIP сам по себе не гарантирует прохождение модерации или показ рекламы.
