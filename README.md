# Tango

Tango — русскоязычная браузерная логическая игра для компьютера и мобильных устройств. Заполните поле солнцами и лунами: в каждой строке и каждом столбце их должно быть поровну, три одинаковых символа подряд запрещены, а соседние клетки со связью `=` или `×` должны соответственно совпадать или различаться. Повторяющиеся строки и столбцы разрешены. Доступны размеры 6×6, 8×8 и 10×10.

Подсказка объясняет логический шаг и выделяет опорные клетки; применение шага подтверждается отдельно. `getHint` получает только условия задачи и текущее поле, без готового ответа. Игра сохраняет состояние локально в браузере, включая счётчик начатых партий; сброс и продолжение той же партии счётчик не увеличивают.

В автономной версии подсказки бесплатны. В версии для Яндекс Игр межстраничная реклама запрашивается перед партиями 3, 6, 9 и далее. При ошибке или недоступности рекламы подсказка бесплатна. Если показанное видео закрыто без события `onRewarded`, награда не выдаётся. Фактический показ зависит от платформы и не проверен без аккаунта.

## Запуск

Проверена Node.js 24; для выпуска нужны также npm и Python 3.9 или новее. Установите зависимости и запустите сервер разработки:

```sh
npm ci
npm run dev                              # автономная версия
VITE_GAME_PLATFORM=yandex npm run dev    # адаптер Яндекс Игр
```

Для проверки готовых сборок через локальный статический сервер:

```sh
npm run build
npm run preview:standalone
npm run preview:yandex
```

Серверы preview запускаются в отдельных терминалах. Вне Яндекс Игр SDK по `/sdk.js` может быть недоступен; адаптер перейдёт в резервный режим. Проверки и выпуск:

```sh
npm run typecheck
npm test
npm run test:e2e
npm run build
npm run release
```

Для Chrome e2e и отдельной проверки типов сценариев см. [инструкцию тестирования](docs/05-testing.md). Последняя команда повторно выполняет проверки и сборку, создаёт два ZIP и манифест, проверяет архивы и распаковывает их во временный каталог. Подробности — в [инструкции выпуска](docs/RELEASE.md).

## Устройство

- `src/core` — генерация, проверка, поиск решений и распространение ограничений.
- `src/hints` — объяснимые логические подсказки без доступа к ответу.
- `src/platform` — автономный адаптер и адаптер Яндекс Игр, реклама и события платформы.
- `src/main.ts` и `src/style.css` — интерфейс и локальное сохранение.
- `src/app` — состояние и связь с worker.
- `src/workers` — генерация и поиск подсказок вне главного потока.

Правила и алгоритмы описаны в [спецификации](docs/01-algorithms.md), подсказки — в [отдельном документе](docs/02-hints.md), задачи и контракты — в [плане](docs/PLAN.md). [Результаты эксперимента](docs/01-verification.json) содержат проверочные задачи и решения и не являются форматом игровых подсказок.
