# Tango

Браузерная логическая игра с полями 6×6, 8×8 и 10×10. Подготовлен статический каркас; игровое ядро и интерфейс находятся в разработке. Правила и алгоритмы описаны в [спецификации](docs/01-algorithms.md), задачи и контракты — в [плане](docs/PLAN.md). [Результаты эксперимента](docs/01-verification.json) содержат проверочные задачи и решения, но не являются форматом игровых подсказок.

Для работы необходимы Node.js и npm:

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

Сборки создаются в `dist/standalone` и `dist/yandex`; по отдельности их запускают команды `npm run build:standalone` и `npm run build:yandex`. Результаты предназначены для обычной статической раздачи. Платформа задаётся переменной `VITE_GAME_PLATFORM` во время сборки. Публикация в Яндекс Играх пока не предусмотрена.
